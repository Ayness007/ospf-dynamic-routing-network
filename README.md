# ospf-dynamic-routing-network
This project demonstrates the design and configuration of a multi-router network using Cisco Packet Tracer and OSPF (Open Shortest Path First) as the dynamic routing protocol. The network was designed to provide communication between multiple IP networks through dynamic route exchange between Cisco routers.
*The topology consists of: 4 Cisco 2911 routers, 2 Cisco 2960 switches, Multiple PCs, Multiple interconnected IP network and OSPF-enabled router links

*Technologies Used*: Cisco Packet Tracer, Cisco IOS, IPv4 addressing, OSPF dynamic routing, Ethernet networking, Network troubleshooting and ICMP/Ping
The command below was used to verify OSPF neighbor relationships: show ip ospf neighbor. 
The routers successfully established FULL OSPF neighbor relationships.
The routing table was checked using: show ip route
End-to-end connectivity was tested using: ping 192.168.2.10
